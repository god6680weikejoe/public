# 哥姐弟漫游之旅（第一版）

## 本地预览

直接双击 `index.html` 即可打开。

## 功能

- 手机/电脑端自适应布局
- 单一日常生活照片墙（无分类筛选与分类标签）
- 点击卡片大图预览
- 首屏入场动效、滚动显现、卡片轻 3D 悬停
- 大图预览开关过渡 + 手机左右滑动切图
- 键盘操作：`Esc` 关闭，`←/→` 切换

## 替换成你的照片

编辑 `app.js` 中的 `photos` 数组：

- `title`：照片标题
- `thumb`：列表缩略图地址
- `src`：预览大图地址

你可以先用图床 URL；后续也可把图片放到本目录（例如 `./assets/xxx.jpg`）并改为本地路径。

## 背景音乐

- 将音乐文件放到：`./assets/music/bgm.mp3`
- 页面右下角有“播放音乐”按钮，可手动开关
- 浏览器若阻止自动播放，第一次点击页面后会自动尝试播放

## 上线方式（静态托管）

### Vercel

1. 新建仓库并上传本目录文件
2. 在 Vercel 导入该仓库
3. Framework 选 `Other`（或自动识别）
4. Build Command 留空，Output Directory 留空
5. Deploy

### Netlify

1. 打开 Netlify 后台
2. 直接把本目录拖拽到 Deploy 页面
3. 完成后即可获得可访问链接
